# OpenPassportSwift (iOS Only)

> **Status (2026-10-30): graduates in 0.5.0; the repo is archived after that release.** The current
> code is the `passport_mrz` circuit, `circuits/passport_mrz`:
> - It proves that a DSC signed this passport's MRZ, and that a device key signed the verifier's challenge.
> - The verifier (`verify_passport_mrz`) chains that DSC to a **pinned CSCA list**.
> - SRS is sized at 1×.
>
> **Passport proofs from 0.3.x–0.4.0 are not bound to any issuing state.** Read
> [`SECURITY.md`](SECURITY.md) before relying on any of them.
>
> Creds (the app this was built for) no longer ships passport ZK. Its
> "real person" signal is a device-attested statement after native passive
> authentication (App Attest / Android Key Attestation), checked with plain
> JWT-style signature verification. The rest of this README describes the
> historical package layout.
>
> Build and check 0.5.0:
> ```bash
> cd circuits && nargo test --package passport_mrz && nargo compile --package passport_mrz
> cp target/passport_mrz.json ../mopro-binding/test-vectors/noir/
> cd ../mopro-binding && cargo run --release --bin gen_srs -- \
>   --circuit test-vectors/noir/passport_mrz.json --out test-vectors/srs/passport_mrz.srs.bin --exact
> cargo test --release passport_mrz -- --include-ignored
> ```

Noir passport ZK circuits + mopro bindings packaged in a `SemaphoreSwift`-style Swift Package for iOS.

OpenAC-mode additions are included:
- `prepare_link` circuit for Prepare-phase commitment.
- `show_link` circuit for Show-phase challenge/scoped linking.
- Swift helpers for OpenAC prepare/show/link verification.

For a repo-level technical audit and manual verification guide, see [`NOIR_TECHNICAL_VERIFICATION.md`](NOIR_TECHNICAL_VERIFICATION.md).

## Repository Format

```text
circuits/                    # Noir circuits
├── passport_verifier/       # RSA-SHA256 signature verification (DSC → SOD)
├── data_integrity/          # DG hash chain verification (SOD hash matching)
├── disclosure/              # Selective disclosure (nationality, age, name from MRZ)
├── prepare_link/            # OpenAC prepare-phase commitment (offline)
└── show_link/               # OpenAC show-phase challenge binding + scoped linking (online)
mopro-binding/               # Rust FFI + mopro iOS build entry
├── src/bin/
└── test-vectors/noir/
Package.swift                # Swift Package manifest
Sources/
  OpenPassportSwift.swift    # Swift package entry point + OpenAC helpers
  MoproiOSBindings/          # Generated by mopro (mopro.swift + xcframework)
Tests/
  OpenPassportSwiftTests.swift
openAC.md                    # OpenAC paper ↔ implementation mapping
```

## iOS-Only Scope

- Supported: iOS bindings and Swift Package integration.
- Not included: Android bindings.
- On non-iOS platforms, the package now compiles with a fallback shim (for tooling/tests), but proving/verification APIs throw unavailable-platform errors.

## Build iOS Bindings

```bash
# 1) Compile and test circuits
make circuits

# 2) Build mopro iOS bindings and sync them into Sources/MoproiOSBindings
make build-ios

# Optional: include Intel simulator slice too
# IOS_ARCHS="aarch64-apple-ios,aarch64-apple-ios-sim,x86_64-apple-ios" make build-ios
```

`make build-ios` does:
1. Copy compiled circuit JSON files to `mopro-binding/test-vectors/noir/`
2. Run `IOS_ARCHS=<...> IPHONEOS_DEPLOYMENT_TARGET=15.0 CONFIGURATION=release cargo run --bin ios`
3. Sync `mopro-binding/MoproiOSBindings` to `Sources/MoproiOSBindings`
4. Auto-patch `mopro.swift` with a non-iOS fallback shim so `swift build/test` on macOS still works

## Use as Swift Package

### Option 1: Xcode

1. In Xcode: `File` → `Add Package Dependencies`
2. Enter this repo URL
3. Add product: `OpenPassportSwift`

### Option 2: `Package.swift`

```swift
dependencies: [
    .package(url: "https://github.com/kidneyweakx/conductor-playground.git")
],
targets: [
    .target(
        name: "YourApp",
        dependencies: ["OpenPassportSwift"]
    )
]
```

### Option 3: CocoaPods

```ruby
pod 'OpenPassportSwift', :git => 'https://github.com/kidneyweakx/conductor-playground.git'
```

## Swift Usage

```swift
import OpenPassportSwift

let circuitPath = Bundle.main.path(forResource: "disclosure", ofType: "json")!

let inputs: [String: [String]] = [
    "mrz_data": mrzFieldValues,
    "mrz_hash": mrzHashValues,
    "disclose_nationality": ["1"],
    "disclose_older_than": ["0"],
    "disclose_name": ["0"],
    "age_threshold": ["18"],
    "current_date": currentDateYYMMDD,
    "out_nationality": outNationality,
    "out_name": outName,
    "out_is_older": ["0"]
]

let result = try generateNoirProof(circuitPath: circuitPath, srsPath: nil, inputs: inputs)
let isValid = try verifyNoirProof(proof: result.proof, vk: result.vk)
```

## OpenAC Swift Helpers

```swift
import OpenPassportSwift

let prepareCommitment = try computeOpenACPrepareCommitment(
    sodHash: sodHash,
    mrzHash: mrzHash,
    linkRandomness: linkRandomness
)

let request = OpenACShowRequest(
    challenge: challenge,
    linkMode: .scopedLinkable,
    linkScope: linkScope,
    epoch: Data([0x20, 0x26, 0x03, 0x15])
)

let ok = try verifyOpenACLinking(
    prepare: artifact,
    show: presentation,
    request: request,
    nowUnix: UInt64(Date().timeIntervalSince1970)
)
```
